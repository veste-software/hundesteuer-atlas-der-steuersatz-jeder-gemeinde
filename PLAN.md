# PLAN: Hundesteuer-Atlas (NRW prototype)

Read `SPEC.md`, `DESIGN.md` and `CLAUDE.md` first. Order: green scaffold → one real municipality page end to end (Paderborn) → more fixtures and the harvest → hubs and homepage → refresh and polish. "AC n" refers to the acceptance criteria in SPEC.md §6.

Suggested libraries (no UI kits): `unpdf` (PDF text, no native deps), `node-html-parser` (HTML), `robots-parser` (robots.txt). Network access happens only in `pipeline/` scripts run with `npm run …`, never in `npm run build` or `npm test` (tests use fixtures and mocked fetch).
